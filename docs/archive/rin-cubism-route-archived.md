# RIN Cubism Route Archived

Cubism / real Live2D is no longer the current production body route for RIN.


Old Cubism resources were removed from active runtime locations because the previous model route produced poor visual quality, weak positioning, nearly static behavior, and no reliable production-ready state/motion system.

Future Cubism work is possible only if the owner explicitly reopens the route and provides or approves a properly authored model with usable `.moc3`, `.model3.json`, expressions, motions, physics, and clear integration acceptance criteria.

Until then:

- do not load Cubism assets as the production body;
- do not expose Cubism as the active renderer;
- do not depend on old `public/live2d/` files;
- keep the UI label truthful: Active body renderer is Layered Avatar.
