# Live2D Cubism Framework WebGL Shaders

This directory contains the WebGL shader resources required by the Live2D
Cubism SDK for Web R5 Framework renderer.

Source archive:

- Live2D Cubism SDK for Web R5 (`CubismSdkForWeb-5-r.5.zip`)
- Framework path: `Framework/Shaders/WebGL/`

License notes:

- Framework shader sources are governed by the Live2D Open Software License.
- Cubism Core remains under the Live2D Proprietary Software License and is kept
  separately in `public/live2d/cubism-core/`.

RIN uses these files only as local browser renderer resources for the owner-run
desktop/web UI. They do not store identity, memory, policy, prompts, API keys,
or provider data.
